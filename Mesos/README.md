## Esecuzione del jar

Posto che il percorso per la cartella \bin del jdk sia già incluso nella variabile d'ambiente PATH,
per l'esecuzione del progetto è sufficiente usare i seguenti comandi:

Esecuzuine server:

> java -jar server.jar

Esecuzione client:

> java -jar client.jar
